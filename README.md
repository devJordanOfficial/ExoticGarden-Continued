# ExoticGarden-Continued

ExoticGarden is a [Slimefun 5](https://github.com/Slimefun5/Slimefun5) addon which brings various new plants, fruits, vegetables and food items to the game.

You can find more Information on the **outdated** BukkitDev page:
https://dev.bukkit.org/projects/exotic-garden

## Requirements

- [Paper](https://papermc.io) 26.1.x or newer
- [Slimefun 5](https://github.com/Slimefun5/Slimefun5) built against 5.1.2 (not tested on older versions)

## Building

1. Clone this repository
2. Run `./gradlew shadowJar` (requires Java 25)
3. The output jar will be in `build/libs/`
